> Monday, one star: my 9 a.m. standup lasted 47 minutes, nobody stood up, and my inbox hit triple digits before I'd found coffee.

A one-line review of my Monday — no title, no explanation, just the line.

## Run it

```bash
python3 main.py
# writes the line to /output/entry.txt
```

Set `OUTPUT_DIR` to write somewhere else, e.g. `OUTPUT_DIR=/tmp/monday-out python3 main.py`.
